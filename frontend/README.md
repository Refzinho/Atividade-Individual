# Front-end do TreinaCreator

Interface em Next.js com App Router. Para executar, rode `npm install` e `npm run dev` nesta pasta, após iniciar a API na pasta `../backend`.

As páginas estão em `src/app`, os componentes reutilizáveis em `src/components` e as chamadas à API em `src/lib/api.js`.

As instruções completas estão no [README principal](../README.md).
